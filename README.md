# Tano

تحديث Tano بواجهة أكثر اكتمالاً للتجربة قبل النشر.

## الموجود في النسخة الجديدة
- لوحة تحكم حديثة.
- صفحة مستقلة للمراقبة الحية.
- صفحة مستقلة للسجل التاريخي.
- صفحة مستقلة للتنبيهات.
- صفحة مستقلة لتحليل الذكاء الاصطناعي.
- صفحة إعدادات تشمل اللغة، الحساب، الملف الشخصي، الإشعارات والخصوصية.
- واجهة عربية وإنجليزية.
- إضافة image_picker لتجهيز اختيار صورة الملف الشخصي.

## التشغيل
1. افتح المشروع في Flutter.
2. نفّذ `flutter pub get`.
3. نفّذ `flutter run`.

## مهم قبل النشر
تسجيل الدخول الحقيقي بحساب Google والإشعارات الفورية الحقيقية يحتاجان إعداد Firebase/Google للمشروع وربطهما بالكود.
كما أن ربط AI بخدمة خارجية يحتاج Backend/API آمن؛ لا تضع مفتاح API سري داخل التطبيق.

القراءات الحالية في هذه النسخة تجريبية وليست من مستشعر طبي حقيقي.
